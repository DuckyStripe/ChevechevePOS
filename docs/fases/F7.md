**Decisiones de este brief** (ya escritas en CONTRATOS §2.8/§4.4):

- **Orden de candados de dinero**: ruta → turno → pedido → líneas → venta → cliente → existencias (`producto_id`) → CxC
  (`id`) → abono. Ninguna función lo invierte (las de 007 ya van ruta → pedidos → existencias).
- **Idempotencia**: entregar (clave de la venta), venta, abono, devolución y **gasto** (`movimiento_caja.clave_idempotencia`,
  nuevo: el gasto en ruta es acción del repartidor con mala señal, P5) con clave; iniciar, terminar, no entregado y liquidar
  idempotentes por estado. 008 rehace `fn_iniciar_ruta` y `fn_terminar_ruta` con la misma firma para cumplirlo.
- **Paradas de solo cobro (movidas de F6)**: `fn_agregar_cobro` + `fn_sugerencias_cobro` (B9); se cierran con un abono que
  trae `ruta_parada_id` (→ `visitada`) o con «No entregado» (→ `fallida`, sin pedido ni aviso).
- `fn_puede_ver_aviso` (misma firma de 3 argumentos) suma `wa_nota_entrega` a las plantillas de reparto.
  `fn_seguimiento_pedido` (misma firma) agrega `recibio` en `entregado`; la foto nunca sale al cliente.
- «Mandar datos de transferencia» y «Recordar saldo» crean avisos manuales (`POST /avisos` exige `pedidos.ver`): el rol
  Repartidor no tiene el botón; con la semilla actual lo usan Dueño y Administrador (R8).
- Saldo inicial desde Eleventa: `vence_el = fecha local del corte + cliente.dias_credito`; concepto = `--concepto`
  obligatorio (dato, no texto en el código); un cliente que ya tiene una CxC `saldo_inicial` se salta (idempotente).
- `/caja` completa nace en F7 (abrir mostrador, movimientos, resumen, cerrar con contado): la entrega «recoge» y las
  cancelaciones con reembolso necesitan turno de mostrador. F8 agrega solo supervisión de turnos ajenos y la hoja de corte.

Pruebas de API obligatorias (código exacto; nunca un 404 que «pasa»):

- **Flujo de ruta completo** con el juego de B por HTTP: iniciar con fondo → entregar P1 parcial (201) y repetir (200 mismo

  terminar → `GET /rutas/:id/liquidacion` con `efectivo_esperado "950.00"` → liquidar `940.00` → `diferencia "-10.00"`.
- **Comprobante**: PNG real → 201 `{comprobante}`; archivo de texto con extensión `.jpg` → 400 `IMAGEN_NO_VALIDA`; > 1 MB →
  413 `ARCHIVO_GRANDE`; `GET` sin `cobranza.ver` ni `rutas.liquidar` → 403.
- **Permisos**: Repartidor entrega solo pedidos de su ruta (ajena → 403 `RUTA_AJENA`); Repartidor `POST /rutas/:id/liquidar`

- **Cliente**: `GET /publico/estado-cuenta` de C da el mismo `saldo_final` que `GET /clientes/:id/estado-cuenta`;
